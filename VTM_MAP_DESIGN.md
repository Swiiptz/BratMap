# bratMap - Design et UX

## Direction artistique

Esthetique sombre, moderne, elegante, cartographique, avec une ambiance de renseignement et une touche nocturne VTM. Ne pas tomber dans le rouge/noir gothique caricatural.

## Carte

- fond sombre et desature ;
- routes hierarchisees visuellement ;
- grands axes facilement identifiables ;
- batiments gris ;
- parcs sombres ;
- eau peu saturee ;
- textes lisibles mais secondaires ;
- donnees de chronique prioritaires visuellement.

## Palette

Base : noir, anthracite, gris froid.

Couleurs reservees aux informations : territoires, pings, plots, souterrains, itineraires.

Ne pas utiliser la couleur comme seul indicateur : completer avec forme, icone, contour ou motif.

## Pings

- petits marqueurs modernes ;
- pas de gros pins facon Google Maps ;
- pictogrammes sobres ;
- legere augmentation / glow discret a la selection ;
- labels selon zoom.

## Territoires

- remplissage transparent ;
- contours propres ;
- couleur libre ;
- option contour uniquement ;
- chevauchements lisibles ;
- edition fluide des sommets.

## Souterrains

- couche specifique ;
- lignes lisibles et legerement lumineuses ;
- niveau selectionne mis en avant ;
- niveaux adjacents attenues si utile ;
- pointilles pour passages supposes ;
- surface toujours perceptible en arriere-plan.

## Panneaux

- sombres ;
- legerement translucides ;
- effet de verre tres discret ;
- fins et repliables ;
- ne pas masquer inutilement la carte.

## Typographie

Police moderne, sobre, tres lisible. Pas de police gothique pour le corps du texte.

## Animations

- rapides ;
- discretes ;
- transitions de zoom ;
- ouverture/fermeture de panneaux ;
- apparition des zones ;
- surbrillance selection ;
- animation legere des itineraires.

Pas de HUD futuriste surcharge.

## Experience globale

Le produit doit donner l'impression d'un vrai outil cartographique de chronique : propre, serieux, immersif et utilisable longtemps sans fatigue visuelle.
